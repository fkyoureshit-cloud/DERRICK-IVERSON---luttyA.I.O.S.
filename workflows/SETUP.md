# Workflow Setup & Configuration Guide

## 📋 Quick Reference

### Utilities Setup
- **Get Time**: No dependencies, returns instantly
- **Execute**: Requires Elastic Defend endpoints
- **Get Action Status**: Requires HTTP Connector
- **Invoke Workflows**: Requires target workflow IDs

### AI Agents Setup
- Requires Agent Builder setup in Kibana
- Need agent IDs configured

### Firebase Setup
- Firebase project required
- Credentials stored in Elasticsearch index

### Search Setup
- **Web Search**: Requires Brave Search connector
- **Semantic Search**: Requires Elasticsearch index with embeddings

---

See inline workflow documentation for detailed configuration of each workflow.
